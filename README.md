# Stand narration files

Recorded narration MP3s for prayers.dougdevitre.org, filed under the hash-keyed paths that audio-manifest.js on main refers to. Deployed as a static site (the prayers-audio Vercel project); it is the origin behind audioManifest.base. Objects are immutable: a changed script or voice setting produces a new key, never an overwrite. Nothing here is edited by hand; the Build audio workflow on main adds files and the matching manifest entry together.

Public origin: https://stand-audio.vercel.app (the prayers-audio Vercel project, bound to this branch).
